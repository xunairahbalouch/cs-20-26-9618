# Cambridge AS & A Level Computer Science 9618 Paper 4 Solutions (2020-2025)

This repository contains Python solutions for Cambridge International AS & A Level Computer Science (9618) Paper 4 Practical exams from 2020 to 2025.

| 2020 | Specimen | Music Database (CSV) | Stack Implementation |
| 2021 | Oct/Nov | Members Database (CSV) | Linked List / Queue |
| 2022 | Oct/Nov | Routes Database (CSV) | Binary Search Tree |
| 2023 | Oct/Nov | Products Database (CSV) | Searching & Sorting |
| 2024 | Oct/Nov | Recipes Database (CSV) | Hash Table |
| 2025 | May/June | Students Database (CSV) | Recursion |

## Question Topics

### Question 1: Database Operations (CSV)
- Loading data from CSV files
- Searching and filtering
- Adding, updating, deleting records
- Statistical analysis and reporting

### Question 2: Data Structures & Algorithms (2020-2025)
- **2020**: Stack - Push, Pop, bracket validation, string reversal, decimal to binary
- **2021**: Linked List / Queue - Enqueue, Dequeue, animal shelter management
- **2022**: Binary Search Tree - Insert, search, traversal (in/pre/post-order), sort
- **2023**: Searching & Sorting - Linear search, binary search, insertion sort, quick sort, bubble sort, merge sort
- **2024**: Hash Table - Hash function, linear probing, collision handling
- **2025**: Recursion - Factorial, Fibonacci, palindrome, string reversal, binary search, towers of Hanoi

## Requirements
