# Cambridge 9618 Paper 4 - Sample Data Files

This directory contains sample CSV data files for testing the Python solutions.

## Files

- `music.csv` - Sample music track database
- `members.csv` - Sample library members database  
- `routes.csv` - Sample transport routes database
- `products.csv` - Sample products inventory database
- `recipes.csv` - Sample recipe database
- `students.csv` - Sample student records database

## Usage

Each data file corresponds to Question 1 of the respective year:

| Year | Data File | Description |
|------|-----------|-------------|
| 2020 | music.csv | TrackID, Title, Artist, Genre, Duration |
| 2021 | members.csv | MemberID, Name, MembershipType, YearJoined, Fines |
| 2022 | routes.csv | RouteID, Origin, Destination, Distance, Duration, Price |
| 2023 | products.csv | ProductID, Name, Category, Price, Stock |
| 2024 | recipes.csv | RecipeID, Name, Cuisine, PrepTime, CookTime, Difficulty, Servings |
| 2025 | students.csv | StudentID, Name, House, Year, Grade |

## Creating Sample Data

The Python solutions will work with any CSV file following the column structure. Create your own data files or use the exam-provided data files during the actual exam.
